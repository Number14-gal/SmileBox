SmileBox

SmileBox is a browser-based music editor for creating, editing, and sharing chiptune music.

The original BeepBox project is free to use. If you would like to support its creator, you can donate here:


SmileBox is based on JukeBox, developed by CoolTasDude. If you would like to support Slarmoo, creator of Slarmoo's Box, you can donate here:

About

SmileBox is a modification of JukeBox, originally developed by CoolTasDude. JukeBox is based on Slarmoo's Box, which builds upon UltraBox and other BeepBox-based projects.

SmileBox does not claim ownership over songs created with it, so original songs belong to their authors.

Neither SmileBox nor its creators assume responsibility for any copyrighted material played on SmileBox. No songs are ever received, recorded, or distributed by SmileBox's servers. All song data is contained in the URL after the hash (#) mark, and SmileBox running inside your browser converts that data into sound waves.

SmileBox does not collect, track, or share any user data.

Keybinds List:

If you are new to BeepMods, the first three sections contain the most important keybinds.

General

  • Spacebar: play or pause the song
  • Shift Spacebar: play from mouse location
  • Z: undo
  • Y or Shift Z: redo
  • C: copy pattern from selection
  • V: paste pattern into selection
  • X: cut pattern
  • +/-: move notes up or down
  • Shift & +/-: move notes up or down one octave
  • Shift + Drag: select notes or patterns

Patterns, Channels, and Bars

  • 0-9: assign pattern number to selection
  • Arrows: move selection
  • D: duplicate a pattern
  • N: create a new blank pattern
  • Delete: clear pattern data
  • A: select entire song
  • Shift A: select current channel
  • Enter: add a new bar after the currently selected one
  • Shift Enter: add a new bar before the currently selected one
  • Backspace: delete currently selected bar
  • Ctrl Enter: add channel
  • Ctrl Backspace: delete currently selected channel
  • Ctrl & Arrows: move selected channel up or down

Channel Muting

  • M (or Shift S): mute/unmute a channel
  • S: solo/unsolo a channel
  • Shift M: mute/unmute entire song

Playhead

  • [ ]: move playhead backward or forward one bar
  • F: move playhead to start
  • Shift F: move to start of loop
  • H: move playhead to highlighted pattern
  • B: loop selected bars

Instruments

  • Shift C: copy instrument settings
  • R: select random preset
  • Shift R: generate random instrument
  • Alt R: generate random instrument with same type
  • T: select next preset
  • Alt E: open/close all envelope dropdowns
  • Alt F: open/close all FM dropdowns

Simultaneous Instrument Per Channel (if enabled)

  • Alt Enter: add instrument within channel
  • Alt Backspace: delete instrument within channel
  • Shift 0-9: select/toggle corresponding instrument within channel

Song Player

  • Spacebar: play or pause the song
  • [ ]: move playhead backward or forward one bar
  • F: move to first pattern
  • L: toggle loop
  • Z/+/-: toggle zoom
  • Shift E/P: return to editor
  • Shift U: shorten song player link

Miscellaneous

  • Shift ~: new blank song
  • Shift P: open song player
  • Shift U: shorten song URL
Preset Tags List:

All tags have no spaces and are case insensitive.

BeepBox Category Tags

  • Retro, Keys, Idiophone, Guitar, Picked, Distortion, String, Vocal, Brass, Reed, Flute, Pad
  • Drums (all drum types), HiHat, Snare, Kick, Novelty

Special Category Tags

  • Featured: instruments selected by the original project developer
  • Bass: instruments that work best at low pitches
  • Lead: instruments that work best at high pitches
  • Ambience: ambient background sounds, like wind
  • Chiptune: chipwaves with minimal effects
  • Dubstep: instruments suited to dubstep sounds
  • SFX: instruments that resemble specific sound effects

Instrument Type Tags

  • FM (any), FM4op, FM6op
  • Supersaw, PWM (pulse width), PickedString, Harmonics, Spectrum, Noise, Drumset

FAQ:
Why are the tags not working?

Currently, instrument tags only affect the R (random preset) and T (next preset) keybinds. Tags have no effect on the instrument type dropdown.

Changing how the instrument type dropdown functions is complicated, so this may not change soon.
